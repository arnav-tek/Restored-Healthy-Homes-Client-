# Owner walkthrough for the current prototype

22 October 2026. Use fictional information. This guide describes the current demo, not live operating procedures. No email, payment, booking, upload or permanent account is created.

## Enter and switch workspaces

Start at `/demo/walkthrough`. For the owner workspace, open `/admin/login`, expand Quick access, choose Administrator and select Sign in. For member examples, use `/login` and its Quick access choices. These select fictional identities; they do not authenticate anyone.

Keep the walkthrough in the same tab and use site links. Switch account or Sign out clears unsaved drafts and photo previews; submitted records remain in that tab. Accept the discard prompt only when the draft can be lost. Refresh, a full page navigation, closing the tab or confirmed workspace reset loses session changes. Separate tabs do not share them. Reset asks for confirmation; cancelling leaves the current work intact.

## Review an application and listing

1. Submit a fictional business through List Your Business.
2. Sign in as Administrator. In Applications, open the submitted business and approve or reject it, using the provided decision controls.
3. Approval leaves membership inactive. Switch to Your submitted application, open Membership, choose one example category, review simulated checkout and simulate success. Alternatively, use the admin Membership scenario with a note and confirmation.
4. In Listings, open the record and expand Edit business profile. Save business details, categories, services and credential claims. The local member and admin views use the same accepted record.
5. Review the public-field preview. Optional public owner/professional name and public email are separate from private application contact information. Leaving them blank does not publish private contacts.

An eligible listing must be approved, have active membership and have no suspension. Payment scenarios cannot undo rejection or suspension. The public directory retains its original sample listings and adds the eligible submitted application in this tab. Follow Find this business in the directory or View public profile from the application/membership review. Refresh or reset removes it; private application contacts remain excluded.

## Credentials and featured placement

Review claims in Credentials. New or edited claims require review; changing a certification reference does not verify a member. Approval, membership, suspension, credential verification and featured entitlement remain separate.

In Featured, select a record, apply a sample entitlement and follow View homepage featured examples. Submitted applications and the explicitly linked Fern & Field, Cedar Path and Hearthside examples update the homepage in this tab. Other workspace studios have no public profile link and remain in the admin placement preview only; the page explains this. Removing entitlement, suspension or inactive membership removes a linked homepage card. Softwood remains an independent seeded public example. Homepage order follows the public catalog, then the submitted application; final paid upgrade and ranking rules remain undecided.

## Demonstrate billing without a payment service

Use a member account and open Membership. Inactive/canceled accounts can start simulated checkout; active accounts can try a renewal; past-due/unpaid accounts can review recovery. Review one category's reference rate and the $0 demo charge, then choose a successful or failed result. A failure sets past due; a successful retry restores active membership. Leave checkout/recovery to keep the current status.

Review cancellation, then Keep current status or Confirm simulated cancellation. Confirmation sets canceled immediately for this walkthrough; no refund, real invoice or renewal date is created. Real timing/grace/refund policies still need approval. Reopen checkout to show returning. These outcomes update the submitted application's directory/profile visibility and linked homepage featured eligibility. Existing directory fixtures stay seeded. Approval, suspension, credentials and featured entitlement never change through billing.

Only one category is priced in each example; it does not combine charges or change the business's categories. Added-category rates are explicitly marked previews. Accepted outcomes remain when switching accounts in the same tab. Unfinished checkout/recovery/cancellation reviews clear on sign-out; profile edits and admin membership changes clear that record's billing screen. Reset/reload clears all outcomes.

## Categories and education references

In Categories, create a category using a unique name, description and explicit preview price. Existing category IDs and prices stay intact when a display name changes. Added categories appear in application/profile, question and consultation selectors and analytics in this tab. The canonical directory catalog and pricing page retain the approved eight categories; added categories are also available to the directory filters in this tab. New prices are examples, not agreed billing.

In Certifications, select a category, enter program/provider details with an HTTPS reference, requirements, steps, timeline and costs. Save a draft, review it, then publish. The public Certifications view shows the published version in this tab. Editing returns it to draft; original reference copy remains until republished. Use sample content until final sources are approved.

## Resources

In Content, create or edit a resource using plain text. Save the draft and open Review saved article. Publish to showcase after reviewing it, then follow View published resources to browse the article. Drafts are excluded from public results. Editing a published article returns it to draft. Refresh/reset makes session-created article links unavailable; the page offers a return to Resources.

## Questions, consultations and reviews

- **Q&A:** submit a sample category question, publish it as admin, then switch to an eligible category member to answer. Use Hearthside Building Co. for Healthy Home Builders. Admin reviews the first eligible response before publication. No category email is sent; the final publication policy needs approval.
- **Consultations:** submit a free phone request, assign an eligible participating category member as admin, then switch to that member to accept or decline. Opting out prevents new assignment/acceptance. No appointment or call is booked and no notification is delivered.
- **Reviews:** submit fictional feedback on a sample profile, review it in the admin Reviews queue and inspect published ratings/member visibility. These are not verified customer reviews.

In a member Profile, the phone-consultation checkbox changes local participation. A JPEG/PNG/WebP sample photo can be previewed, removed and replaced. It is never uploaded or published.

## Analytics and recovery

Analytics shows total applications, active memberships, eligible listings, application counts for a selected UTC month, membership states and category counts. If the browser shows a text field, type the complete month as YYYY-MM. An incomplete/invalid month shows an em dash for that count until corrected. Multi-category members count in each category; these are not revenue figures. Original example applications use October 2026 dates. Activity lists recent accepted admin changes, not a durable audit log.

For a missing record or cleared article, return to its list. For an empty directory, use Browse specialists to clear filters. If the city map or video is unavailable, use the city link or static background. For a complete clean walkthrough, use the confirmed workspace reset and sign in again.
