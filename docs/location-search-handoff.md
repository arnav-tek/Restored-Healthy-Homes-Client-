# Connected location search — 15 November 2026

Implemented; **live geocoding and authenticated saved-location acceptance remain BLOCKED**. Existing design, sessions, public eligibility, reviews, demo mode and disabled application email remain intact. No deployment, push, memberships activated, provider account created or billing enabled.

## Behavior

- Connected homepage/directory accept US ZIPs (including leading zeros) and city names with optional state abbreviation. Lookup is submit/button based, never per keystroke. Accessible candidate buttons require an explicit selection, including ambiguous city names. No result is treated as a successful match by text alone.
- Category, state, business/service text, published rating, Any distance / 10 / 25 / 50 / 100 miles and nearest sorting compose before six-item database pagination. Search URL stores the provider-resolved `place` UUID, display `location`, existing filters, sort and page. Pagination/profile returns reuse that ID without provider calls. Raw coordinate parameters are rejected; point ranges/order are validated at provider, DTO and database boundaries.
- Geographic points are **approximate city/ZIP centers**, not homes or service boundaries. Any-distance ordinary searches retain records without coordinates. Radius/nearest searches exclude them; maps omit their markers and the UI reports missing coordinates. Existing legacy coordinates are neither trusted, backfilled nor silently geocoded.
- Members have a separate explicit **Save public location** control. Only their owned listing is derived from the current validated identity. A resolved place UUID is required; browser owner IDs, coordinates and protected fields are rejected. Saving updates public city/state and the profile version. Ordinary city/state edits or ownership transfers invalidate an old map association. Clear + save removes coordinates. Failures/stale versions retain the choice, with compare/reload controls. Other profile details may need reload after a location save.
- **Show map** loads MapLibre/OpenFreeMap on demand. Markers represent only the current results page. Overlapping marker hit areas group at the current zoom (including nearby distinct centers), with keyboard-accessible markers with safely constructed text summaries and profile-return links. Scroll zoom is disabled; cooperative gestures, loading/error/retry states and a complete results-list alternative remain available. Tile failure never removes search/list controls. Optional device geolocation was not added.

## Provider terms and attribution checked

- [Geoapify pricing](https://www.geoapify.com/pricing/) and [credit costs](https://www.geoapify.com/pricing-details/): Free commercial use with required attribution; **3,000 credits/day, up to 5 requests/second**. A simple geocode is one credit. Credits are not visitors; retries, other applications and other APIs can consume the same allowance. No free uptime guarantee is assumed; [terms](https://www.geoapify.com/terms-and-conditions/) disclaim uninterrupted service.
- [Geoapify geocoding/storage FAQ](https://www.geoapify.com/geocoding-api/) permits stored results with source attribution. This adapter currently accepts **OpenStreetMap-sourced** city/postcode results only; unknown sources are discarded rather than stripped of attribution. Geoapify and OSM links appear beside search information. Private query cache has a **30-day reuse TTL**; expiry prevents reuse, not a promised physical deletion deadline. Approximate place/provenance records remain for saved listings and stable shared URLs; no raw search text or IP address is stored. Pseudonymous limiter rows expire and are pruned on later lookup requests; no retention scheduler is enabled.
- [OpenFreeMap](https://openfreemap.org/) allows commercial public-instance use without registration, keys or advertised request/view limits; it offers **no SLA**. [Quick start](https://openfreemap.org/quick_start/) specifies its style URL and OpenFreeMap/OpenMapTiles/OSM attribution, retained in the map and adjacent links. No bulk/offline downloading was added.
- [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/docs/) **6.18.0**, BSD-3-Clause, is the only new application dependency. Bundled CSS is lazy-loaded with the map; its worker is served from the fixed same-origin `/api/map-worker` route with build tracing. CSP adds same-origin workers, map image blobs/data and the exact tile host; no wildcard remote-script or arbitrary upstream permission. [Supabase PostGIS guidance](https://supabase.com/docs/guides/database/extensions/postgis) informed geography/meter queries and longitude-first point construction.

## Configuration and operation — not enabled

Ignored server configuration, placeholders only:

```ini
GEOAPIFY_API_KEY=<approved-geoapify-free-key>
RHH_LOCATION_GATEWAY_KEY=<random-server-only-capability-at-least-32-characters>
GEOAPIFY_DAILY_BUDGET=2400
```

User confirms **no Geoapify key**. No gateway secret has been generated/registered. Once authorized provider access exists, an operator securely configures both server-only values and registers **only SHA-256(gateway key)** using the restricted SQL-operator function:

```sql
select rhh_private.configure_geocoding('<sha256-of-server-capability>', 2400);
```

Ordinary members/anonymous users cannot call this registration function. Never publish either key or use the Storage/service-role key for directory queries. Restart the local server after configuration. Key presence is not provider verification. A future capability rotation requires coordinated server/hash replacement; email credentials/configuration are unrelated.

The database gateway must authorize every cache/lookup write using the registered capability. Durable limits: **10 requests/minute and 100/day per pseudonymous client bucket**, global **4 provider attempts/second**, default **2,400 attempted provider calls/UTC day**. The lower server/database budget wins; configured maximum is 2,800 for headroom. Vercel uses its overwritten forwarding header; local/other hosts deliberately share a conservative bucket until an approved trusted-proxy strategy exists. Never trust arbitrary forwarded IP headers.

Cache misses use a locked 25-second query lease; duplicate/concurrent lookups return busy, abandoned leases can recover, and at most **one** retry is allowed for timeout/5xx, charged before each provider attempt. 429/configuration failures are not retried. Fixed US/type-specific upstream URL, bounded query/response sizes, six-second request deadlines, sanitized errors and no raw location logging. Provider errors never overwrite member drafts. No automatic provider requests occur during directory pagination.
