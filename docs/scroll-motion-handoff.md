# Public-page scroll animations — 24 October 2026

Scope: expand the existing three homepage entrances into coordinated scroll motion across the public site. No integrations, content changes, new dependencies, deployment or video controls are part of this request.

## Behavior and coverage

`src/components/ui/scroll-effects.tsx` is a small client controller mounted once inside the root main landmark. Server Components and existing public projections remain unchanged. Explicit `data-scroll-reveal` markers opt content into a 24px rise over 660ms. Sibling groups stagger by 64ms, capped at 192ms; the About story media adds a gentle 0.97-to-1 scale over 760ms. Individual translate/scale properties preserve existing hover transforms. Content retains full opacity throughout.

The homepage now animates journey steps, specialty cards, About highlights, feature cards, featured listings, review-process items and the specialist CTA. Other marked content includes About, Certifications, Pricing, directory cards and profile information, Resources and article sections, questions/answers, consultation process steps, Contact, public application/question headings and legal placeholders. Forms, filters, status messages, header/footer navigation and member/admin/sign-in workspaces stay steady.

One IntersectionObserver reveals each element once. A scoped child-list MutationObserver registers streamed or newly inserted public cards and forgets removed nodes. Path changes clean up the previous observer and active animations; query/filter updates can be handled without a pathname change. There is no per-frame React state, scroll listener, scroll hijacking or browser storage.

Reduced-motion preference changes cancel effects immediately. Keyboard focus and pointer-down inside moving content cancel its animation so interactive targets settle. Without JavaScript, IntersectionObserver or the animation API, content remains visible in its normal layout. No opacity hiding, fixed delays on content availability or persistent transforms are used. The earlier removal of all hero playback controls remains in place.
